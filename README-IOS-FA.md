# alo iOS — کد بازبینی‌شدهٔ 2.4.2+7

این بسته **سورس کد است، نه فایل نصب APK یا IPA**. قابلیت جدید، سرویس ابری یا صفحهٔ اضافی به اپ افزوده نشده و ظاهر قبلی حفظ شده است.

## اصلاحات محدود
- سری‌سازی شروع، پایان، لغو و آزادسازی ضبط برای جلوگیری از تداخل عملیات و آزادسازی حین پردازش native.
- پاک‌سازی فایل موقت حتی اگر شروع یا پایان ضبط با خطا مواجه شود.
- لغو ضبط با رفتن برنامه به پس‌زمینه؛ جلوگیری از ادامهٔ شروع ضبط در صفحهٔ غیر‌فعال.
- اعمال حد ۶۰ ثانیه مستقل از خطای سنجش بلندی صدا.
- حذف رد زودهنگام گفتار آرام بر اساس دسی‌بل؛ تشخیص گفتار واقعی VAD همچنان فعال است.
- رد عددهای دارای جداکنندهٔ هزارگان نامعتبر و مقیاس‌های تکراریِ مبهم، به‌جای حدس‌زدن مبلغ.
- حفظ محاسبات مالی دقیق مبتنی بر BigInt، تأیید دستی خروجی گفتار و تمام امکانات موجود.

نرخ ضبط WAV تک‌کانالهٔ 16 kHz متناسب با Whisper حفظ شده است. مدل، تنظیمات اصلی تشخیص و موتور خواندن فارسی جایگزین نشده‌اند؛ افزایش دقت گفتار یا کیفیت صدای دستگاه اندازه‌گیری نشده است.

## مدل‌های حذف‌شده از فایل‌های ورودی
هر دو ZIP اولیه فاقد **۳۶۰ فایل مدل ASR/TTS** بودند: مدل ASR با اندازهٔ 874,188,075 بایت و مجموع فایل‌های TTS برابر 81,531,770 بایت. فایل VAD و فونت موجودند. پوشه‌های خالی دارایی صرفاً ساختار مورد انتظار Flutter را نگه می‌دارند و مدل محسوب نمی‌شوند.
ابزار `restore_models.py` این فایل‌ها را از APK قبلی بازیابی و با اندازه/SHA256 مانیفست موجود تطبیق می‌دهد. هیچ مدل ساختگی، جایگزین یا لینک دانلود حدسی اضافه نشده است.

## ساخت iOS روی Mac
نیازمند macOS، Xcode، CocoaPods و Flutter 3.35.7 است؛ حداقل سیستم پروژه iOS 17 است.
```bash
python3 restore_models.py /path/to/previous-alo.apk
python3 verify_models.py
bash build-ios.sh
```
اسکریپت فعلی ابتدا ساخت بدون امضا را بررسی می‌کند. سپس `ios/Runner.xcworkspace` را در Xcode باز کنید و تیم اپل، شناسهٔ بسته و امضای مناسب را تنظیم کنید. برای خروجی قابل نصب/توزیع، پس از تنظیم امضا:
```bash
flutter build ipa --release
```
خروجی IPA در `build/ios/ipa/` قرار می‌گیرد. نصب به روش توزیع و پروفایل امضا وابسته است؛ فایل بدون امضا قابل نصب روی آیفون نیست. کد native Swift و وابستگی‌های iOS در این محیط کامپایل نشده‌اند.
