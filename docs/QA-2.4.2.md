# گزارش واقعی بازبینی alo 2.4.2 — ios

## نتیجهٔ تازه
- Flutter 3.35.7 / Dart 3.9.2، محیط Linux.
- `flutter analyze --no-pub`: بدون ایراد.
- `flutter test --no-pub --reporter json`: **629 تست موفق، ۰ شکست**.
- شامل ۱۸ تست جدید عددهای بدفرمت/مقیاس تکراری، حفظ تبدیل‌های دقیق و صف عملیات async پس از خطا.
- تست‌های موجود پارسر، محاسبات، ذخیره‌سازی، امنیت نصب بسته و رابط کاربری هم اجرا شدند.
- اسکریپت‌های Python از نظر syntax و اسکریپت‌های shell با `bash -n` بررسی شدند.

## مرز این نتایج
تست صف، رفتار هم‌زمانی را با عملیات مصنوعی بررسی می‌کند، نه با میکروفون واقعی. تست‌های iOS روی Flutter/Linux اجرا شده‌اند، نه iPhone یا iOS Simulator. هیچ مدل صوتی، تبدیل صدای واقعی، کیفیت TTS، مصرف حافظهٔ مدل یا دقت گفتار در این بازبینی سنجیده نشده است.

## مانع فایل نصب
۳۶۰ فایل اصلی ASR/TTS در ZIP ورودی وجود ندارند و بازیابی نشده‌اند؛ چک واقعی `verify_models.py` با خطای Missing/wrong model متوقف شد. هیچ مدل جعلی برای دورزدن این کنترل قرار داده نشده است.
APK تازه تولید نشده: مدل‌ها، کلید اصلی امضا و ابزار Android SDK در اختیار این ساخت نیستند.
IPA تازه تولید نشده: macOS/Xcode، مدل‌ها و پیکربندی امضای اپل لازم است. اسکریپت iOS روی Linux مطابق انتظار از ساخت جلوگیری کرد.

## پذیرش روی گوشی
اجازه/رد میکروفون، گفتار آرام/کوتاه و سکوت، محدودیت ۶۰ ثانیه، لمس سریع پایان، رفتن به پس‌زمینه، بستن صفحه در پردازش، آماده‌سازی مدل و کمبود فضا، متن مالی واقعی و تأیید پیش از ذخیره، بازخوانی فارسی و مصرف RAM را بررسی کنید.
گزارش‌های `docs/history` متعلق به نسخه‌های قبلی‌اند و به این ساخت تعلق ندارند.
