# alo — پروژهٔ آیفون ۲.۴.۱

**این بسته سورس پروژه است، نه IPA و نه برنامهٔ قابل نصب روی آیفون.**
نسخهٔ نصب‌شدنی هنوز تولید نشده است: محیط آماده‌سازی Linux است و Xcode، کامپایلر SDK اپل، پروفایل امضا و آیفون واقعی در اختیار آن نبودند. کد Swift فقط از نظر ساختار/نحو بررسی شده، نه با کامپایلر اپل. اولین ساخت روی Mac ممکن است به اصلاح وابستگی‌های CocoaPods یا اتصال native نیاز داشته باشد.

## موارد حفظ‌شده
- موتور نرمال‌سازی و استخراج اعداد فارسی، پارسر مالی، محاسبه، مدل تراکنش، ساختار SQLite و فرم بررسی دقیقاً از alo ۲.۴ اندروید حفظ شده‌اند.
- هزینه، درآمد، بدهی، مطالبات، تسویه‌های مرتبط، انتقال، ثبت چند ردیف با تأیید، گزارش‌های شمسی و خروجی CSV/JSON.
- همان مدل Whisper فارسی Q8_0 و همان صدای فارسی Mana Piper. تمام ۳۶۰ فایل ASR/TTS با اندازه و SHA256 نسخهٔ قبلی تطبیق داده شدند؛ مدل کوچک‌تر یا کم‌دقت‌تر جایگزین نشده است.
- پردازش صوت آفلاین؛ نیازی به API key یا دریافت مدل در زمان استفاده نیست. اینترنت برای نصب ابزارها و وابستگی‌های توسعه روی Mac لازم می‌شود، نه برای پردازش صدای کاربر در برنامه.

## تغییرهای آیفون و ظاهر
- پُل Swift برای کپی مدل‌ها از بستهٔ برنامه، به‌صورت جریان ۶۴ کیلوبایتی و بررسی SHA256، بدون بارگذاری مدل ۸۷۴ مگابایتی در حافظهٔ رابط.
- کنترل فضای دیسک و حافظهٔ مجاز همان فرایند iOS؛ پاک‌سازی کپی نیمه‌تمام قبلی؛ مدل‌های کپی‌شده از بکاپ iCloud مستثنا شده‌اند.
- مجوز میکروفون فارسی، پیکربندی iOS 17+، پروژهٔ Xcode مطابق Flutter 3.35.7، آیکون سبز بدون شفافیت و manifest اولیهٔ حریم خصوصی.
- ورودی نرم صفحات، موج ظریف روی کارت خلاصه، نوار پایین شیشه‌ای در فضای مستقل Scaffold، واکنش فشاری و لمس میکروفون، جابه‌جایی Cupertino. Reduce Motion رعایت می‌شود. فاصلهٔ کنترل‌ها برای فونت بزرگ اصلاح شد.

## ساخت روی Mac
1. Flutter **3.35.7**، Xcode و CocoaPods را نصب و آماده کنید. این پروژه برای **iOS 17 به بالا** و آیفون تنظیم شده است.
2. بسته را کامل استخراج کنید؛ پوشهٔ `assets` باید پس از اجرای ابزار بازیابی، شامل مدل‌های حجیم شود. آن را حذف نکنید.
3. در پوشهٔ پروژه اجرا کنید:

```bash
python3 verify_models.py
bash build-ios.sh
```

اسکریپت فقط روی macOS اجرا می‌شود؛ وابستگی‌ها، تحلیل، تست‌های Flutter و **ساخت بدون امضا** را اجرا می‌کند. ساخت بدون امضا به‌تنهایی قابل نصب نیست.

4. پروژهٔ **`ios/Runner.xcworkspace`** را در Xcode باز کنید، نه فایل xcodeproj. در Signing & Capabilities، تیم اپل خود را انتخاب کنید. Bundle ID پیش‌فرض `ir.alo.aloFinance` است؛ اگر برای تیم شما قابل ثبت نیست، شناسهٔ اختصاصی انتخاب کنید.
5. برای تست، آیفون را به Xcode متصل و نسخهٔ Release را اجرا کنید. بعد از تنظیم صحیح امضا، خروجی IPA را با روش مجاز توزیع برای تیم خود بسازید؛ برای TestFlight، تنظیمات Apple Developer/App Store Connect لازم است. هیچ کلید یا رمز اپل داخل این بسته وجود ندارد و نباید آن را در چت ارسال کرد.

## بررسی‌های انجام‌شده و انجام‌نشده
- تست‌های Dart/Flutter روی Linux اجرا شده‌اند، نه روی iOS Simulator یا آیفون. تست‌های مشترک محاسبات و شش تست جدید UI/افکت/Reduce Motion/Safe Area وجود دارند.
- پیش‌نمایش‌ها با Flutter روی Linux، با تم iOS و فضای امن شبیه‌سازی‌شده رندر شده‌اند. این تصاویر، اسکرین‌شات آیفون واقعی نیستند و داده‌ها صرفاً آزمایشی‌اند.
- سه تست native در `ios/RunnerTests` برای اجرا در Xcode ارائه شده‌اند؛ در این محیط اجرا نشده‌اند.
- مدل‌ها همان مدل‌های نسخهٔ اندروید هستند، اما سرعت، مصرف حافظه، گرما، کیفیت ضبط میکروفون و دقت خروجی روی آیفون **هنوز اندازه‌گیری نشده‌اند**. حفظ مدل و منطق مالی به معنی تضمین عملکرد یکسان روی تمام آیفون‌ها نیست.

## پذیرش لازم روی آیفون واقعی
- آماده‌سازی اولیهٔ مدل، از جمله فایل‌های TTS دارای فاصله در نام، بدون خطای MissingPlugin/asset و بدون کپی نیمه‌تمام.
- ضبط با اجازه/رد اجازه، گفتار کوتاه، سکوت، رفتن برنامه به پس‌زمینه، قطع و برگشت صدا.
- تست جمله‌های مالی واقعی با صدای خود کاربر؛ بازخوانی فارسی و بررسی عدد/نوع/شخص/تاریخ.
- تأیید دو ردیف مستقل، ذخیره و بازگشایی؛ خطای ثبت بدون تغییر جزئی داده‌ها؛ تسویهٔ جزئی و مانده.
- صفحه کوچک، فونت بزرگ، کیبورد و Reduce Motion؛ نبود هم‌پوشانی با نوار پایین، ناحیهٔ امن و کیبورد.
- اجرای Release و سنجش زمان و RAM و گرما. مدل بزرگ روی بعضی آیفون‌ها ممکن است از سقف حافظهٔ برنامه فراتر برود. در کمبود حافظه، متن/ورود دستی راه جایگزین است؛ مدل کوچک‌تر خودکار انتخاب نشده است.

## نکات مهم
- چند گیگابایت فضای آزاد برای بسته، نصب و کپی اولیهٔ مدل‌ها لازم است. مدل صوتی کوچک یا نسخهٔ ابری جایگزین نشده است.
- انتقال مالی از اندروید به آیفون با خروجی JSON و بازیابی در تنظیمات انجام می‌شود؛ همگام‌سازی خودکار وجود ندارد. ابتدا از داده‌های قبلی پشتیبان بگیرید.
- JSON/CSV حاوی اطلاعات خصوصی‌اند و رمزگذاری نشده‌اند. پشتیبان‌گیری سیستمی داده‌های مالی تابع تنظیمات دستگاه است؛ پردازش آفلاین به معنی خاموش‌کردن بکاپ سیستمی کاربر نیست.
- این برنامه حسابداری شخصی است، نه سامانهٔ حسابداری دوبل/مالیات/حقوق‌ودستمزد/حسابرسی رسمی.
- پیش از انتشار عمومی، مجوز مدل‌ها و کتابخانه‌ها و سیاست‌های اپل باید بررسی شوند؛ وابستگی espeak-ng/GPL در صدای فعلی خصوصاً مهم است. manifest حریم خصوصی، پذیرش App Store را تضمین نمی‌کند.

نتیجهٔ نهایی این آماده‌سازی: **۶۱۱ تست Dart/Flutter موفق و تحلیل بدون اخطار**. این عدد شامل تست native اپل نیست؛ خروجی IPA تولید نشده است.
