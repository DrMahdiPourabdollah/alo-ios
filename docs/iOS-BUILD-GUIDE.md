# راهنمای ساخت نسخهٔ iPhone (IPA) — alo 2.4.2

این سند توضیح می‌دهد چطور از این کد، یک فایل `.ipa` قابل‌نصب روی آیفون بسازید — از جمله روش‌های **رایگان و بدون نیاز به مک**.

> نکتهٔ مهم: این آرشیو «کد کامل و بازبینی‌شدهٔ iOS» است، اما سه چیز برای تولید IPA لازم است و هیچ‌کدام داخل کد نیست:
> 1. ماشین **macOS + Xcode** (یا یک سرویس بیلد ابری که مک در اختیار می‌گذارد)
> 2. **فایل‌های مدل** (۳۶۰ فایل ASR/TTS که عمداً از آرشیو حذف شده‌اند)
> 3. **امضای اپل (Code Signing)** برای نصب روی دستگاه واقعی

---

## گام ۰ — بازیابی مدل‌ها (اجباری، قبل از هر بیلد)

بدون این فایل‌ها اپ کامپایل می‌شود ولی قابلیت‌های صوتی کار نمی‌کنند. مدل‌ها دقیقاً از APK منتشرشدهٔ اندروید بازیابی می‌شوند (بدون دانلود، بدون جایگزینی):

```bash
python3 restore_models.py /path/to/alo-2.4.2-Offline-Financial.apk
python3 verify_models.py
# باید چاپ کند: All 360 ASR/TTS model assets match the original release manifest.
```

در بیلد ابری، این گام را داخل خودِ pipeline انجام می‌دهیم (فایل APK را به‌عنوان یک artifact رمزگذاری‌شده آپلود می‌کنید).

---

## مسیر A — GitHub Actions (رایگانِ واقعی، بدون کارت بانکی) ✅ پیشنهادی

GitHub برای هر حساب، رانر `macos` رایگان می‌دهد (برای ریپوی عمومی کاملاً رایگان؛ برای خصوصی ۲۰۰۰ دقیقه در ماه رایگان). فایل workflow آماده در همین بسته است:

    .github/workflows/ios-build.yml

**مراحل:**
1. کل این پوشه را در یک ریپوی GitHub بگذارید (فایل‌های مدل را آپلود نکنید — آن‌ها در بیلد بازیابی می‌شوند یا جداگانه به‌عنوان Secret/Release اضافه می‌شوند).
2. به `Actions` بروید و workflow با نام **Build iOS (alo)** را اجرا کنید.
3. خروجی:
   - اگر امضا تنظیم نشده باشد → یک `Runner.app`/archive **بدون امضا** می‌گیرید (برای تست کامپایل و شبیه‌ساز).
   - اگر گواهی‌ها را به‌صورت Secret اضافه کنید → یک **`alo.ipa` امضاشده** می‌گیرید.

ساخت **unsigned** رایگانِ رایگان است. ساخت **IPA امضاشدهٔ** قابل‌نصب روی آیفون شما، به یک هویت امضا نیاز دارد (گام «امضا» در پایین).

---

## مسیر B — Codemagic (پلن رایگان، مخصوص Flutter)

Codemagic ماهانه حدود ۵۰۰ دقیقه بیلد رایگان روی مک می‌دهد و بومیِ Flutter است. فایل آمادهٔ `codemagic.yaml` در ریشهٔ همین بسته هست.

1. در codemagic.io ثبت‌نام کنید و ریپو را وصل کنید.
2. workflow `ios-alo` اجرا می‌شود.
3. برای IPA امضاشده، حساب Apple Developer را در بخش Code signing وصل کنید (Automatic).

## مسیر C — مک شخصی + Xcode

```bash
bash build-ios.sh                 # اعتبارسنجی مدل‌ها + کامپایل unsigned
# سپس:
open ios/Runner.xcworkspace       # تیم اپل را انتخاب و امضا کنید
```

## گام «امضا» و نصب رایگان روی آیفون — مهم

کامپایل را می‌توانید رایگان در ابر انجام دهید، اما برای **نصب** روی آیفون باید اپ امضا شود. دو حالت دارید:

| حالت | هزینه | محدودیت |
|------|-------|---------|
| **Apple ID رایگان** (Free Provisioning) | رایگان | اپ هر **۷ روز** منقضی می‌شود و باید دوباره امضا شود؛ حداکثر ۳ اپ هم‌زمان |
| **Apple Developer Program** | ۹۹ دلار در سال | امضای کامل، نصب دائمی، انتشار در App Store / TestFlight |

**نصب رایگان با Apple ID معمولی (بدون ۹۹ دلار):**
IPA/`.app` ساخته‌شده در ابر را با یکی از این ابزارها روی آیفون بریزید (با همان Apple ID رایگان خودتان امضا می‌شود):
- **Sideloadly** (ویندوز/مک) — ساده‌ترین گزینه
- **AltStore / SideStore** — روی خود آیفون نگه می‌دارد و خودکار هر هفته دوباره امضا می‌کند

> واقعیت صادقانه: «رایگانِ کامل» یعنی اپ شخصی ۷‌روزه که هر هفته باید refresh شود. اگر نصب دائمی یا توزیع برای دیگران می‌خواهید، به حساب توسعه‌دهندهٔ ۹۹ دلاری اپل نیاز دارید — این بخش از هیچ ابزاری رایگان نمی‌شود چون محدودیت خود اپل است، نه کد.
